# Shailendra Vishwakarma — Portfolio

Simple portfolio built with **Express** and static HTML / CSS / JS.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy (GitHub Pages)

```bash
npm run deploy
```

Live: https://Shailendra0320.github.io/shailendra-portfolio/
